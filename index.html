How to Use

Setup Instructions

Replace your browser's default new tab with this lightweight, customizable page:

  1. Download the extension: new-tab-alt-ext.zip from GitHub releases
  2. Extract the ZIP file to a folder on your computer
  3. Open Chrome and go to chrome://extensions/
  4. Enable "Developer mode" (toggle in top right corner)
  5. Click "Load unpacked" and select the extracted folder
  6. Right-click the extension icon → Click "Options" (or go to extension details → "Extension options")
  7. The custom URL is already set to https://czampath.github.io/new-tab-alt/ — just click "Save Settings"!
  8. Open a new tab to see your custom page

Alternative: You can also use the 3rd party extension Override Chrome's New Tab from the Chrome Web Store if you prefer.

Why Use This?

• Bypass organization-enforced new tab pages
• Lightweight (~30KB) and fast performance
• Fully customizable with your own bookmarks and settings
• No data collection or privacy concerns
