Override New Tab Settings

Customize what URL loads when you open a new tab

Enter any URL you want to load when opening a new tab. Leave empty to use Chrome's default new tab page.

Supported URL formats:

  • https://example.com
  • http://localhost:3000
  • file:///C:/path/to/file.html
  • chrome://newtab
  • chrome-extension://[id]/page.html

URL Redirects

Automatically redirect specific URLs to different destinations
